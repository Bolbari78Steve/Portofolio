# Portfolio IgoTech - Documentation

## 📝 Description
Portfolio numérique pour l'agence digitale IgoTech présentant :
- Ses services (création web, réseaux sociaux, marketing digital)
- Ses réalisations (galerie de projets)
- Les témoignages clients
- Un système de contact

## 🛠 Technologies utilisées
- **Frontend** :
  - HTML5, CSS3, JavaScript
  - Framework CSS : Bootstrap 5
  - Icônes : Font Awesome

- **Compatibilité** :
  - Mobile-first design
  - Compatible tous navigateurs modernes
  - Temps de chargement optimisé
